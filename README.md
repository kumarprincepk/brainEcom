brainEcom – Brainey Test Assignment
This project demonstrates a simple authentication flow followed by a product listing experience. The application focuses on mobile-based login using OTP verification and a basic post-login dashboard.

The application starts with a login screen where the user is required to enter their mobile number.
<img width="1920" height="1080" alt="Screenshot (94)" src="https://github.com/user-attachments/assets/1799922a-bbec-4b8e-854a-3ad868bb6bb9" />

If the user tries to continue without entering a mobile number, or enters a number that starts with a digit less than 6, an error message is shown asking the user to provide a valid mobile number.
<img width="1920" height="1080" alt="Screenshot (95)" src="https://github.com/user-attachments/assets/7f476b01-9318-4fed-8b3e-fbf4ea750df5" />

Once a valid mobile number is submitted, the user is redirected to the OTP verification screen
<img width="1920" height="1080" alt="Screenshot (96)" src="https://github.com/user-attachments/assets/f7ec410b-5c4c-4e20-9f29-e328c9a91e02" />

The OTP screen contains input fields for entering the one-time password.
<img width="1920" height="1080" alt="Screenshot (97)" src="https://github.com/user-attachments/assets/a7b7746d-d2ac-4449-bf40-94cf4fe337b6" />

After successful OTP verification, the user is logged into the application and redirected to the Product Listing.
Top Left: Displays the logged-in user’s name.
Top Right: Contains a logout button for ending the session.
Main Section: Displays a list of available products.
